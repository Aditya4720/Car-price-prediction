# Car Price Prediction

## Problem
Buyers and sellers struggle to find 
fair car prices in the market.

## Solution
ML-powered web app that predicts 
accurate car resale price based on 
key features.

## Features
- Predict price based on brand, year, 
  fuel type, transmission
- Simple and clean web interface
- Instant results

## Tech Stack
- Python
- Scikit-learn
- Flask
- HTML & CSS
